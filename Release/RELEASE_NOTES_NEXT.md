# 晤言 v1.5.0 发布说明

这是年度主题色、年度归档与年度 PDF 日记本版本。使用同一 NAS 同步的所有设备都应先升级到支持 `daynote-mood` 的版本，再继续记录或同步日级心情。

本版本支持每年保存预设或自定义主题色，颜色可通过 HEX 或系统取色器设置，且兼容旧主题配置。

年度归档支持 WebDAV / NAS 和本地加密文件两种目的地，归档前展示范围，校验成功后才清理本地内容，并保留变化记录。本地归档支持口令验证、只读查看、重新定位、Finder 显示和恢复到 App。

年度 PDF 日记本支持 A5 / A4、素纸文集、时光手帐和年度影集样式，包含日记、日札、标签、照片及音视频说明。

本版本同时保留 Word 导出、日记锁定、富文本编辑和 WebDAV 诊断能力。Word 导出在沙盒内使用进程内 ZIP 写入，并在替换已有文件前完成 XML 校验。

日级心情现在支持明确清除：即使当天只有旧条目心情，清除后也不会再次被兼容逻辑显示，旧条目原始值仍保留。

升级前请确认已有同步数据完整。旧版客户端无法识别日级心情能力；检测到未知同步能力时，新客户端会停止写入并提示升级，不会静默覆盖远端心情。
