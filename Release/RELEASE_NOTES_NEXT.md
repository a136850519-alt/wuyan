# 晤言 v1.3.0 发布说明

这是 1.2.x 的修复版本。使用同一 NAS 同步的所有设备都应先升级到支持 `daynote-mood` 的版本，再继续记录或同步日级心情。

本版本修复了 Word 导出、日记锁定、富文本切换保存和 WebDAV 诊断问题。Word 导出在沙盒内使用进程内 ZIP 写入，并在替换已有文件前完成 XML 校验。

日级心情现在支持明确清除：即使当天只有旧条目心情，清除后也不会再次被兼容逻辑显示，旧条目原始值仍保留。

升级前请确认已有同步数据完整。旧版客户端无法识别日级心情能力；检测到未知同步能力时，新客户端会停止写入并提示升级，不会静默覆盖远端心情。
