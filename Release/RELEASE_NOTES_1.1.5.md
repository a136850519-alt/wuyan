# 晤言 1.1.5

本版本包含 V4 代码审查修复，覆盖同步拉取冲突、归档前同步、年份下载保护、媒体校验、备份还原、提醒取消、AI 隐私门控和测试隔离等问题。

## 同步升级要求

V3-15 修改了同步 manifest 协议，新增永久保留的 `purged` 清除记录。**所有同步到同一个 NAS 的设备都必须升级到 1.1.5（至少 1.1.4）。**旧版客户端可能丢弃该字段，并可能把已删除的日记重新推回 NAS；完成升级前不要让旧版客户端继续参与同一 NAS 的同步。

带路径前缀的 WebDAV 地址此前可能未执行远端到期清理（V4-06）；升级后请在确认远端备份完整后再使用清理功能。大文件加密传输仍使用现有协议，分块 AEAD 方案待后续单独决策。
