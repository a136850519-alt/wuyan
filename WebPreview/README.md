# 晤言 · 1010 网页验收预览

直接打开 `index.html` 即可离线浏览，请保留同目录的 `WenKai.ttf` 与 `preview.js`。

这是设计稿的交互验收版本，使用示例日记。心情、天气、提纲、标题及冲突处理仅作用于页面内示例，刷新后重置，不访问真实数据库、AI 或同步服务。

网页已去除设计审阅顶栏和底栏。通过工具栏“新建日记”打开今日一句话，通过左下角设置进入冲突列表。日记时间线含同日三个板块及一篇历史记录，可检查共享心情和历史日期隔离。正文下方可撤销插入的示例提纲。

原生源码实施与测试说明见 `../docs/interface-1010/README.md`。打包安装等待用户确认。
